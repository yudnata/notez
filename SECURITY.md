# Keamanan

Notvas masih dalam pengembangan. Perbaikan keamanan ditujukan ke source pada branch utama; belum ada kebijakan dukungan untuk versi lama.

Workspace `.notvas` berisi teks, tugas, posisi kartu, serta gambar tertanam dalam JSON. Berkas ini tidak dienkripsi. Backup `.notvas.bak` juga dapat berisi data yang sudah dihapus dari versi aktif. Simpan keduanya di lokasi yang sesuai untuk data pribadi.

## Melaporkan masalah

Gunakan [pelaporan kerentanan privat GitHub](https://github.com/yudnata/notvas/security/advisories/new) jika fitur tersebut tersedia pada repository. Jika tidak tersedia, buka issue yang hanya meminta jalur pelaporan privat. Jangan menulis detail eksploitasi, kredensial, atau isi workspace pribadi pada issue publik.

Laporan yang bisa diperiksa memuat commit/versi, lingkungan Windows, langkah reproduksi, dampak, dan contoh berkas dengan data buatan. Proyek ini belum menetapkan waktu respons atau program imbalan.

Bug antarmuka biasa dapat dilaporkan lewat [Issues](https://github.com/yudnata/notvas/issues).
