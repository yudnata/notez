# Changelog

## Unreleased

- Canvas sketsa dengan pena, stabilo, shape, teks, sticky, gambar, dan panah terhubung. Panah lurus/siku/lengkung menyesuaikan ketika shape dipindahkan.
- Penghapus memotong stroke pena/stabilo dan menghapus objek lain secara utuh; ukuran kuas memiliki preview.
- Papan Notes dan Checklist dengan kartu pastel, pencarian judul, drag posisi, menu warna, dan hapus dengan konfirmasi.
- Editor Notes dengan format teks, gambar inline/overlay, undo/redo, dan ekspor HTML/TXT. Checklist memiliki checkbox besar, progres, serta teks selesai tercoret.
- Autosave lokal, backup workspace, dukungan file lama, pan dengan drag kanan, dan Ctrl+scroll untuk zoom.
- Header ringkas dengan judul, menu, toolbar, dan kontrol jendela. Menu Kanban dihapus; data lama tetap dipertahankan.
- Pencarian menu Dokumen tetap terbuka saat kolom diklik atau diketik, lalu menutup saat memilih hasil, klik luar, atau Esc.
- Lisensi MIT proyek, atribusi font/dependensi, generator inventaris lisensi, serta paket portable yang membawa pemberitahuan lisensi. SVG dengan font tertanam menyertakan teks OFL.
- Dokumentasi fitur, penggunaan, development, privasi, kontribusi, keamanan, dan cuplikan UI dengan data demo.

Versi package saat ini adalah `0.1.0`. Daftar ini menggambarkan perubahan pada source dan belum menyatakan adanya release baru yang dipublikasikan.
